Intuition before the derivations

From arc deletion to a valid penalty

A feasible interdiction set removes arcs from the network. We want the penalized shortest-path model to reproduce exactly the residual distances, without explicitly removing these arcs.

Residual graph

Interdicted arcs are absent, so the follower can use only surviving paths.

Penalized graph

The arc remains in the optimization model with additional length M. This must reproduce the same distances as deleting it.

How large does the penalty need to be? Big enough that the penalized route using an interdicted arc cannot beat the surviving detour. But not absurdly large: oversized penalties make the optimization model harder to solve.

A concrete example from the paper

Look at the arc 2 → 1. Its original length is 3. With interdiction budget 2, closing this arc uses up the entire budget, so no other arc can be closed. The shortest detour is 2 → 5 → 4 → 1, with length 1 + 3 + 3 = 7.

Original road: 3   ·   Surviving detour: 7

We need 3 + M ≥ 7, hence M ≥ 4.

Notice: choosing M = 12 would also prevent the penalized route using an interdicted arc, but it would be needlessly large. Our aim is a small, safe M.

The bounding argument: upper and lower distance estimates

For all feasible interdictions, we bound the true distances from above and below.

Upper bound on the residual distance to the head

We want a number that is at least as large as the true surviving distance to the end of the closed arc. One guaranteed surviving path gives us such a ceiling: the shortest surviving path cannot be longer than it.

Lower bound on the residual distance to the tail

We want a number that is no larger than the true surviving distance to the beginning of the closed arc. The original shortest-path distance works: removing roads cannot make travel shorter.

Why use a high estimate for one distance and a low estimate for the other? Because we are trying to be conservative about the extra penalty: make the possible detour look longer, and the distance already traveled look shorter. This gives a penalty that cannot be too small.

Key observation: “Upper-bound the distance we must match; lower-bound the distance we have already paid; subtract the original road length.”

Now the formula in the next section has a meaning: M = maximum of 0 and (distance ceiling − distance floor − original arc length). The remaining lessons show how to build better ceilings and floors from the graph.

The idea

What this rule is trying to do

The strongest rule combines four valid candidates: two global arc bounds and two root-aware bounds. The key is to understand the two different auxiliary flow networks, not only their final minimum.

Throughout, we use the actual five-vertex graph of the APSP paper with budget b=2. Arc labels switch between (length, cost) and (length, auxiliary capacity), as indicated.
Detailed walkthrough

Follow the construction, step by step

Each drawing highlights exactly the arcs used by the argument immediately below it.

1

Fix the target and root. Let a=(1,2), root w=4, budget b=2, and ℓₐ=3. The original shortest root-to-tail distance is d(4,1)=3.

2

Arc-specific auxiliary flow Gᵃᶠ. First remove (1,2), costing 1. One budget unit remains, so kₐ=1. Demand 2 units from tail 1 to head 2. Capacities are 1 on remaining cost-1 arcs and 2 on cost-2 arcs.

3

Two certified u→v paths. Path P₁ = 1→5→3→2, length 9. Path P₂ = 1→5→4→3→2, length 13. Hence μ((1,2))=13−3=10.

4

Root-specific auxiliary flow G₀ᶠ. For μ(4,2), k₀=⌊b/cmin⌋=2, so we seek 3 units from root 4 to head 2. Here every cost ≤2, so every auxiliary arc capacity is 1.

5

Inspect the source cut. Root 4 has only two outgoing arcs, (4,1) and (4,3), each of capacity 1. Their total capacity is 2, so 3 units cannot leave the source. Thus this auxiliary flow is infeasible; μ(4,2)=+∞ in the bound construction.

6

Compute the other root-specific candidate. From M-rtop, σ(4,2)=15. Therefore Δₐ,₄(σ(4,2))=15−d(4,1)−3=15−3−3=9.

7

Take the minimum of all four candidates. The four values are σ(a)=12, μ(a)=10, Δ(σ)=9 and Δ(μ)=+∞. So M-rflow((1,2),4)=9. Here the root-flow term gives no improvement, but rflow retains the best other bound.

The idea in plain language: Combine two ways of avoiding overpayment. First, use real surviving paths instead of imaginary worst-case detours. Second, account for distance already traveled from the source. Keep whichever of the four safe estimates is smallest. The auxiliary flow may fail: that just means this particular certificate cannot help.

The formal definition and proof are given in the manuscript; here we explain the underlying construction and the validity argument.

This illustrates an essential point usually hidden by the formula: the root-specific auxiliary min-cost flow may be infeasible even when every allowed interdiction leaves the graph connected. In that case its candidate is simply omitted / treated as +∞. M-rflow still remains valid because it takes the minimum of the other available valid bounds.

Other big-M rules

M-top — a safe length bound

The first rule deliberately ignores most of the network's structure. It uses one simple fact: a simple detour contains at most n−1 arcs.

M-flow — certify surviving paths

Unlike M-top, M-flow uses a network certificate: a collection of paths with the property that at least one survives every feasible interdiction containing the target arc.

M-rtop — the root changes the penalty

Instead of one arc-only penalty, use a value depending on the shortest-path root. If reaching the tail already costs something, that cost can be subtracted from a root-to-head upper bound.
