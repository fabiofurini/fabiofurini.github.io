Software

Software

Implementations of the algorithms in my papers, released with the benchmark instances and computational material needed to reproduce the experiments.

CliSAT

Exact SAT-based algorithm for the Maximum Clique Problem, used to solve hard maximum clique instances, with benchmark instances and computational material.

Paper: CliSAT: a new exact algorithm for hard maximum clique problems — European Journal of Operational Research, 2023
GitHub ↗

BPP-NE

Numerically exact branch-price-and-cut solver for the classical Bin Packing Problem, with safe dual bounds and an exact fixed-point pricing algorithm.

Paper: A Numerically Exact Algorithm for the Bin-Packing Problem — INFORMS Journal on Computing, 2024
GitHub ↗

NEA-G2KP

Exact solution framework for two-dimensional knapsack problems, with the instances and detailed results of the benchmark study.

Paper: Exact Algorithms for Two-Dimensional Knapsack Problems: A Unified Framework with New Benchmark Results — INFORMS Journal on Computing, 2026
GitHub ↗

Bfilt

Branch-and-filter exact algorithm for Binary Constraint Satisfaction Problems, with a Linux release, benchmark instances and format converters.

Paper: A new branch-and-filter exact algorithm for binary constraint satisfaction problems — European Journal of Operational Research, 2022
GitHub ↗

KPCG

Combinatorial branch-and-bound for the Knapsack Problem with Conflicts, where selected items must satisfy a capacity constraint and pairwise incompatibilities.

Paper: A new combinatorial branch-and-bound algorithm for the Knapsack Problem with Conflicts — European Journal of Operational Research, 2021
GitHub ↗

BBEWC

Exact branch-and-bound for the Maximum Edge-Weighted Clique Problem, with the datasets and the executable used in the computational study.

Paper: A new branch-and-bound algorithm for the maximum edge-weighted clique problem — European Journal of Operational Research, 2019
GitHub ↗

LOC-COV

Branch-and-Benders-cut for the Maximal Covering and Partial Set Covering Location Problems, scaling to millions of demand points.

Paper: Benders Decomposition for Very Large Scale Partial Set Covering and Maximal Covering Location Problems — European Journal of Operational Research, 2019
GitHub ↗

SUB-COV-MAX

Submodular maximization of concave utility functions composed with a set-union operator, for covering and location models with diminishing returns.

Paper: Submodular maximization of concave utility functions composed with a set-union operator with applications to maximal covering location problems — Mathematical Programming, 2022
GitHub ↗

COVER-MAX-DEPTH

Exact separation of cover inequalities of maximum depth for knapsack-constrained problems.

Paper: On the exact separation of cover inequalities of maximum-depth — Optimization Letters, 2022
GitHub ↗

BP-k-VCP

Branch-and-price for the k-Vertex Cut Problem.

Associated paper under review
GitHub ↗

Ramsey lower bounds

Integer programming approach to compute lower bounds for Ramsey numbers using circulant graphs.

Associated paper under review
GitHub ↗
