Stronger Benders cuts: understanding cut-specific coefficients

An interactive explanation of why reducing valid coefficients strengthens the master relaxation.

1. Follow a single requested path

Illustrative directed graph: root 1, requested destination 3; budget 1, unit interdiction costs. Reverse arcs are drawn on the opposite side of the corresponding forward arcs, without overlapping.

The selected shortest path is 1→2→3, with original length L=2. The alternative direct arc 1→3 has length 4. Only arcs a and b belong to the selected path.

θ ≤ L + γaxa + γbxb

2. Why the standard coefficients can be wasteful

Take valid big-M penalties M(a,1)=M(b,1)=3. The standard Benders cut is:

θ ≤ 2 + 3xa + 3xb

But under budget 1, closing either selected arc makes the shortest requested path length 4, an increase of only 2. We can replace the coefficients by 2:

θ ≤ 2 + 2xa + 2xb
Because the master maximizes θ, the smaller coefficients give a stronger upper-bounding inequality.

3. Try the interdictions

4. Exact validity condition

For any selected follower flow with original cost L, nonnegative coefficients γ form a valid cut precisely when, for every budget-feasible interdiction set I:

∑e∈I γe ≥ τK(w,I) − L

With budget 1, the best singleton coefficient is max{0, τ(w,{e})−L}. For larger budgets, singleton coefficients alone may be invalid because the effects of deleting arcs need not add up.

The tree-coefficient rule in v2

For each selected destination t, define U(w,t) as a robust upper bound on the residual shortest-path length. If Tw(e) denotes destinations whose selected paths use arc e, the paper proves validity of:

γe = ∑t∈Tw(e) min { M(e,w), max{0, U(w,t) − length(Pt)} }

This is a valid strengthening of the standard Benders coefficient M(e,w)yew, not necessarily the smallest possible coefficient. In MPSP, only requested destinations contribute to the sum.
