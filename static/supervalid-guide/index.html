Supervalid inequalities: why hitting selected paths is necessary

Explore incumbent-dependent cuts that preserve every strictly improving interdiction decision.

1. A small improvement problem

Illustrative directed graph: root 1, requested destination 3; budget 1, unit interdiction costs. Reverse arcs are drawn on the opposite side of the corresponding forward arcs, without overlapping.

Root 1 must reach destination 3. The selected shortest path is 1→2→3, of length 2, and uses arcs a and b. The incumbent value is 2, obtained without interdiction.

f(x) = shortest residual distance from 1 to 3

Our purpose is to find an interdiction with value strictly greater than 2.

2. An improving decision must hit the selected path

If both a and b remain available, the selected path still exists and has length 2, so the shortest path cannot be longer than 2. Therefore any strictly improving interdiction must remove at least one of them.

xa + xb ≥ 1
This is a supervalid inequality for an improvement problem, not a globally valid inequality for the original feasible interdiction decisions: the no-interdiction decision is feasible and violates it.

4. The general multiple-pairs rule

Take an evaluated interdiction x̂ with follower value f(x̂) ≤ f̄, where f̄ is the current incumbent. Choose one residual shortest path for every requested pair. Let S be the union of arcs in all these paths.

∑e∈S xe ≥ 1

If a candidate violates this inequality, all selected paths survive, so its objective is no greater than f(x̂), which itself is no greater than the incumbent. Thus the excluded candidate cannot strictly improve the incumbent.

The support is aggregated across all active roots and all requested destinations. An improving solution need not hurt every root, so demanding a hit separately for each root would generally be incorrect.

Two refinements in v2

Root subset: using only some roots is valid if the chosen roots' selected-path cost plus valid upper bounds on all remaining roots does not exceed the incumbent.

Cardinality tightening: if the sum of the r largest relevant Benders coefficients added to f(x̂) still does not exceed the incumbent, any improving solution must hit at least r+1 arcs of the union support.

f(x̂)+∑j=1r q(j) ≤ f̄ ⇒ ∑e∈S xe ≥ r+1
The SVI is incumbent-dependent. It should be used in a solver implementing the appropriate strict-improvement / incumbent-update logic, not blindly as an ordinary globally valid cut for the original problem.
