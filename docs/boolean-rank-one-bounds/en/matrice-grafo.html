From matrix to graph

A symmetric $n\times n$ matrix contains $n(n+1)/2$ numbers: $n$ on the diagonal and $n(n-1)/2$ off it. The off-diagonal numbers become edge weights. For the diagonal numbers there are two natural encodings: precisely those of the two manuscripts.

In this chapter: read $\Gamma$ as a weighted graph; see the loop $\ell_i$ (the pseudoforest encoding) and the root edge $(r,i)$ (the encoding of AWCD, Anchored Weighted Clique Decomposition) as two ways of writing the same number $\Gamma_{ii}$; understand why the two encodings carry the same data but not the same combinatorial structure.

Off the diagonal: one edge per pair

Let $V=\{1,\dots,n\}$ be the index set and let $\Gamma\in\mathbb R^{n\times n}_{\ge 0}$ be a symmetric matrix with nonnegative entries. For $i<j$ the number $\Gamma_{ij}=\Gamma_{ji}$ becomes the weight $w_{ij}$ of the edge $\{i,j\}$ of the complete graph on $V$.

By symmetry the upper triangle is enough: each pair is counted only once. There are $\binom n2=n(n-1)/2$ pairs.

In this chapter we use a matrix with six distinct values, so that every number can be recognized at a glance. From Chapter C on we will use the guide's reference example.

The diagonal: two encodings

A simple graph has no place for $\Gamma_{ii}$. There are two natural ways to give it one.

(1) Pseudoforests: one loop per vertex

Add a loop $\ell_i$ (an edge that leaves $i$ and returns to it) with weight $w_{\ell_i}=\Gamma_{ii}$.

The elements are $n$ loops and $\binom n2$ edges. A loop is already a cycle.

(2) AWCD: one extra root

Add a root vertex $r$ (also $i_0$ in the manuscript). The bordered graph is the complete graph on $V\cup\{r\}$, with $w_{ri}=\Gamma_{ii}$ and $w_{ij}=\Gamma_{ij}$.

The anchor is $S=\{r\}$: the vertex that every AWCD clique must contain. The edge $(r,i)$ is an ordinary edge.

Same data

The two encodings are in bijection, element by element:

$$\Gamma_{ii}\ \longleftrightarrow\ \ell_i\ \longleftrightarrow\ (r,i),\qquad\qquad \Gamma_{ij}\ \longleftrightarrow\ \{i,j\}\ \ (i<j).$$

Both have $n+\binom n2=\frac{n(n+1)}{2}$ weighted elements, i.e. exactly the numbers in the upper triangle of $\Gamma$. For $n=3$: three diagonal and three off-diagonal numbers, six in total.

Caution: same data, different structure

The bijection preserves the weights, but it does not say which sets of elements are “independent”. This information is a matroid, and the two encodings suggest different matroids.

  • Encoding (1): a loop is a cycle on its own. Natural structure: the bicircular matroid, whose independent sets are the pseudoforests (every connected component has at most one cycle).
  • Encoding (2): $(r,i)$ is an edge like any other. Natural structure: the graphic matroid of the bordered graph, whose independent sets are the forests (no cycles).

Key takeaways
  • Off the diagonal: $\Gamma_{ij}$ is the weight of the edge $\{i,j\}$ ($i<j$); each pair counts once.
  • Diagonal, pseudoforest encoding: $\Gamma_{ii}$ is the weight of the loop $\ell_i$.
  • Diagonal, AWCD encoding: $\Gamma_{ii}$ is the weight of the root edge $(r,i)$ of the bordered graph on $V\cup\{r\}$.
  • The two encodings carry the same $n(n+1)/2$ numbers, but a loop is a cycle and a root edge is not: the matroid structure (bicircular versus graphic) must be chosen; it is not automatic.
