From the bicircular matroid to matching

A pseudoforest can be recognized with a matching: every element “occupies” one of its endpoints, and no vertex is occupied twice. As a consequence, the value of the optimal pseudoforest becomes the trace $\gamma$ plus the value of a bipartite gain matching.

In this chapter: we see the transversal representation of the bicircular matroid; we start from all the loops and exchange loops for edges; we arrive at the identity $w(F^*)=\gamma+M$.
Notation
$V=\{1,\dots,n\}$ is the vertex set, $\Gamma$ is a symmetric nonnegative matrix and $\gamma=\sum_i\Gamma_{ii}$ is its trace. The graph has a loop $\ell_i$ (an edge from $i$ to $i$) at every vertex, and the edges $\{i,j\}$, $i\neq j$: these are the elements, with weights $w_{\ell_i}=\Gamma_{ii}$ and $w_{ij}=\Gamma_{ij}$. For a set $F$ of elements, $w(F)=\sum_{e\in F}w_e$. A pseudoforest is a set in which every component has at most one cycle (a loop is a cycle); $F^*$ is the maximum-weight pseudoforest returned by the greedy algorithm (Chapter D). Finally, $(t)^+=\max\{0,t\}$.

1. Every element occupies a vertex

An assignment sends every element to one of its endpoints: the edge $\{i,j\}$ to $i$ or to $j$, the loop $\ell_i$ only to $i$. We require it to be injective: all vertices distinct.

Transversal representation
$F$ is a pseudoforest $\iff$ there exists an injective assignment $\varphi:F\to V$ with $\varphi(e)\in e$.
Proof

($\Leftarrow$) The elements of a component occupy distinct vertices of that component, so $\#\text{elements}\le\#\text{vertices}$, i.e. there is at most one cycle (Chapter D).

($\Rightarrow$) In a tree, choose a root and send every edge to its endpoint farther from the root. In a component with a cycle, traverse the cycle in one direction and send every cycle edge to the vertex it enters (a loop to its own vertex); the trees hanging from the cycle send every edge to the endpoint farther from the cycle.

Hall's theorem says the same thing in the bipartite elements–vertices graph: the assignment exists if and only if every set $S$ of elements has at least $|S|$ endpoints. A component with two cycles is precisely a set $S$ that violates it.

2. Start from the loops and exchange

The set of all loops is a pseudoforest: every vertex is occupied by its own loop, and the weight is $\gamma$.

Now replace the loop of $v$ with an edge $\{i,j\}$ that contains $v$, assigned to $v$. The assignment remains injective, and the weight changes by

$$\Gamma_{ij}-\Gamma_{vv}\qquad\text{(the gain of the exchange).}$$

3. Two matchings not to be confused

Each exchange uses an edge and a vertex at most once. Choosing the exchanges is therefore a bipartite matching between edges and vertices, with capacity 1 on both sides.

Gain matching
The edge $\{i,j\}$ assigned to $v\in\{i,j\}$ is worth $(\Gamma_{ij}-\Gamma_{vv})^+$. $M$ is the maximum weight of a matching between edges and vertices with these weights.

4. The identity

Theorem
$$w(F^*)\;=\;\val(P)\;=\;\gamma+M.$$ Hence the pseudoforest lower bound is $\LB=\val(R)-\gamma=M$.
Proof

($\ge$) Given a gain matching, take the selected edges, each assigned to its vertex, and the loops of the remaining free vertices. The assignment is injective, so this is a pseudoforest. Its weight is $\sum_{v\text{ free}}\Gamma_{vv}+\sum_{(\{i,j\},v)}\Gamma_{ij}=\gamma+\sum_{(\{i,j\},v)}(\Gamma_{ij}-\Gamma_{vv})$. With the optimal matching (positive gains only) it equals $\gamma+M$.

($\le$) Let $F$ be a pseudoforest with assignment $\varphi$. Unselected elements: if a vertex $v$ is not occupied, add $\ell_v$; the set remains a pseudoforest and the weight does not decrease ($\Gamma_{vv}\ge 0$). Now every vertex is occupied, either by $\ell_v$ or by an edge $e$ with $\varphi(e)=v$: $$w(F)\le\gamma+\sum_{e\text{ edge}}\bigl(\Gamma_e-\Gamma_{\varphi(e)\varphi(e)}\bigr)\le\gamma+\sum_{e\text{ edge}}\bigl(\Gamma_e-\Gamma_{\varphi(e)\varphi(e)}\bigr)^+\le\gamma+M.$$ The edges together with their $\varphi$ form a gain matching, which gives the last inequality.

Negative gains: an exchange with $\Gamma_{ij}<\Gamma_{vv}$ lowers the weight; keeping the loop $\ell_v$ is better. This is why the matching uses $(\cdot)^+$ and discards those links.

Key takeaways
  • Pseudoforest $\iff$ every element occupies one of its own endpoints, with distinct vertices (Hall).
  • All the loops together weigh $\gamma$; replacing $\ell_v$ with an edge assigned to $v$ gains $\Gamma_{ij}-\Gamma_{vv}$.
  • The transversal matching uses all the elements; the gain matching uses only the edges, with weight $(\Gamma_{ij}-\Gamma_{vv})^+$.
  • $w(F^*)=\gamma+M$, hence the pseudoforest lower bound is $\LB=M$.
