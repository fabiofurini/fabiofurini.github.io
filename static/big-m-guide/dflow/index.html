M-dflow — only the requested destinations

With a proper pair set, an interdicted arc only has to be unattractive for the destinations that are actually requested. See how this changes the penalties on the running example.

OverviewTOPFLOWRTOPRFLOWDFLOW (pair sets)
The idea

What this rule is trying to do

The four rules of the previous lessons ignore which destinations are requested: they bound the residual distance from the root to the head of the interdicted arc. With a pair set 𝒦, only the distances to the requested destinations t ∈ 𝒯w enter the objective, so a path through an interdicted arc a=(u,v) only has to be at least as long as a robust upper bound on dI(w,t).

We use the example of the paper: the running example with budget b=2 and 𝒦 = {(1,4), (1,5)}, so that the only active root is w=1 and its requested destinations are 𝒯1 = {4, 5} (dashed amber circles).
Detailed walkthrough

Follow the construction, step by step

Each drawing highlights exactly the arcs used by the argument immediately below it. Arc labels are (length, cost) unless stated otherwise.

1

The pair set. 𝒦 = {(1,4), (1,5)}, active root w=1, destinations 𝒯1 = {4,5}, budget b=2. The nominal distances are d(1,4)=6 and d(1,5)=3.

2

The smallest valid penalty can drop to zero. Arc (1,2) costs 1, so a feasible interdiction containing it can remove only one more arc of cost 1. The arcs (1,5) and (5,4) cost 2 and always survive, so the requested distances stay d(1,5)=3 and d(1,4)=6, and no penalty is needed on (1,2): η𝒦((1,2),1) = 0. With all pairs, instead, removing (1,2) and (5,3) makes the distance from 1 to the head 2 equal to 13, so η((1,2),1) = 10.

3

Robust upper bounds on the requested distances. The paper uses Uflow(w,t) = min{μ(w,t), σ(w,t)} ≥ dI(w,t) for every feasible I. Here μ(1,t) = +∞, because root 1 has only two outgoing arcs while the flow needs k0+1 = 3 units, and σ(1,4) = σ(1,5) = 13. Hence Uflow(1,4) = Uflow(1,5) = 13.

4

Compare with every requested destination. Mdflow(a,w) = maxt ∈ 𝒯w max{0, Uflow(w,t) − d(w,u) − ℓa − d(v,t)}. For a=(1,2): t=4 gives 13 − 0 − 3 − d(2,4) = 13 − 3 − 4 = 6, and t=5 gives 13 − 0 − 3 − d(2,5) = 13 − 3 − 1 = 9. So Mdflow((1,2),1) = 9, against Mrflow((1,2),1) = 10.

5

Keep the smaller of the two. The paper combines the two rules into the hybrid penalties min{Mrflow(a,w), Mdflow(a,w)}, which are valid for every pair set and coincide with Mrflow when all destinations of the root are requested. The table below gives all arcs for root 1.

The hybrid penalties are smaller than Mrflow on (1,2), (3,2) and (4,3), and their sum drops from 36 to 30. The smallest valid values η𝒦 (sum 3) show how much room is left; they need enumeration and are a theoretical reference only.

The idea in plain language: a shortcut through a closed road is harmless if it does not bring you closer to any place you actually need to reach. The term d(v,t) measures how much of the way to the requested destination is still left after the closed arc.

In the paper. The destination-aware rules Mdtop and Mdflow and the hybrid penalties are defined in the subsection on the destination-aware rule, with their validity proofs. In the experiments with pair sets, the hybrid penalties strengthen the linear relaxation when few destinations per root are requested.
