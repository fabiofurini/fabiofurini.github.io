A step-by-step visual explanation of four polynomial big-M rules — using the real five-vertex graph from the research paper.

01 · The fundamental question

Why do we need a big-M?

In interdiction, the leader removes an arc and the follower recomputes shortest-path distances. Instead of deleting the arc, the formulation adds a penalty when it is interdicted.

\[\ell_a\ \longrightarrow\ \ell_a+M(a,w)x_a\]
Too smallInterdicted arcs may create artificially short paths. The model is incorrect.
Too largeThe integer formulation is valid, but its LP relaxation can become weak.
Goal: make M just large enough that all shortest-path distance values agree with those in the residual graph. Ties involving interdicted arcs are allowed for validity.

03 · Start from the exact answer

What is the smallest valid M?

Fix an interdicted arc \(a=(u,v)\), root \(w\), and feasible interdiction \(I\) containing \(a\). Denote by \(d^I\) the shortest-path distances after deleting all arcs of \(I\).

1Reach the arc's tail \(u\): this costs \(d^I(w,u)\).
2Traverse the removed arc in the penalized graph: add \(\ell_a+M(a,w)\).
3Ensure this is never shorter than the genuine surviving distance \(d^I(w,v)\).
\[d^I(w,u)+\ell_a+M(a,w)\ \ge\ d^I(w,v)\]
\[\boxed{\eta(a,w)=\max\left\{0,\max_{I\in\mathcal I(a)}[d^I(w,v)-d^I(w,u)-\ell_a]\right\}}\]

This is the componentwise smallest valid root-dependent penalty. Evaluating it requires considering feasible interdictions, so we seek polynomial-time upper bounds.

04 · M-top

First idea: use the longest eligible arc lengths

Any simple \(u\)-to-\(v\) path has at most \(n-1\) arcs. Remove arcs that cannot be on such a path — the interdicted arc itself, arcs entering \(u\), and arcs leaving \(v\). Sort the remaining lengths, then add the largest \(n-1\).

\[\boxed{M_{\mathrm{top}}(a)=\sigma(a)=\max\left\{0,\sum_{j=1}^{\min\{n-1,|\mathcal A(a)|\}}\ell_{e_j(a)}-\ell_a\right\}}\]
Example from the paper: for \(a=(2,1)\), the largest eligible lengths sum to 15. The original arc length is 3. Thus \(M_{\mathrm{top}}((2,1))=15-3=\mathbf{12}\).

This is very cheap to calculate but ignores whether the selected arcs actually form a path.

05 · M-flow

Second idea: certify a surviving alternative path

A surprisingly large improvement from one path

Arc \((2,1)\) costs 2 to interdict, so removing it consumes the entire budget. No other arc can disappear. The shortest surviving route is \(2\to5\to4\to1\).

\[d^{\{(2,1)\}}(2,1)=1+3+3=7\quad\Longrightarrow\quad M_{\mathrm{flow}}((2,1))=7-3=\mathbf 4\]
12\(M_{\mathrm{top}}((2,1))\)
4\(M_{\mathrm{flow}}((2,1))\)

What if one further arc can be interdicted?

For \(a=(1,2)\), the interdiction cost is 1; an additional cost-1 arc could also be removed. One replacement path might be broken. Therefore we need two paths such that one is guaranteed to survive.

1The blue path \(1\to5\to3\to2\) has length \(3+4+2=9\).
2The orange path \(1\to5\to4\to3\to2\) has length \(3+3+5+2=13\).
3They share only arcs of interdiction cost 2; with one budget unit left, neither shared arc can be removed. The other cost-1 arcs lie on separate paths.
\[k_a=\left\lfloor\frac{b-c_a}{c^{\min}}\right\rfloor=1,\qquad k_a+1=2\]

A minimum-cost integral flow of two units in the auxiliary capacitated graph provides the guaranteed-survival certificate. The capacities are 1 for arcs affordable after removing \(a\) and \(k_a+1\) otherwise.

\[\mu((1,2))=\max\{9,13\}-3=10,\qquad M_{\mathrm{flow}}((1,2))=\min\{\sigma((1,2)),10\}=\mathbf{10}\]
Why is this safe? At least one path survives any affordable interdiction. The actual shortest path can only be shorter than that surviving path. The length 13 is a guaranteed upper bound, not necessarily the true shortest-path length.
06 · M-rtop

Third idea: the root has already traveled some distance

The global top bound starts at the tail \(u\). But the APSP formulation handles shortest paths from many roots \(w\). A path from \(w\) through \(a=(u,v)\) must already pay at least \(d(w,u)\) to reach \(u\).

\[\Delta_{a,w}(z)=\max\{0,z-d(w,u)-\ell_a\}\]

Apply this transformation to an upper bound \(\sigma(w,v)\) on a surviving root-to-head path, and also retain the global top bound.

\[\boxed{M_{\mathrm{rtop}}(a,w)=\min\{\sigma(a),\Delta_{a,w}(\sigma(w,v))\}}\]
Why root dependence matters: in the paper example, the exact threshold for arc \((1,2)\) is \(\eta((1,2),1)=10\), but \(\eta((1,2),4)=1\). These are exact reference values—not claimed numerical values of the polynomial rtop rule.
07 · M-rflow

Fourth idea: put the two refinements together

Use robust flow paths not only from the arc tail to its head, but also from each root \(w\) to the head \(v\). Let \(\mu(w,v)\) be the corresponding surviving-path upper bound. Then choose the strongest of four individually valid upper bounds.

\[\boxed{M_{\mathrm{rflow}}(a,w)=\min\{\sigma(a),\mu(a),\Delta_{a,w}(\sigma(w,v)),\Delta_{a,w}(\mu(w,v))\}}\]
Important: \(M_{\mathrm{rflow}}\le M_{\mathrm{flow}}\le M_{\mathrm{top}}\) and \(M_{\mathrm{rflow}}\le M_{\mathrm{rtop}}\le M_{\mathrm{top}}\). There is no general dominance order between \(M_{\mathrm{flow}}\) and \(M_{\mathrm{rtop}}\).

09 · What to remember

Four rules, four questions

Top

How long could an alternative be, using only eligible arc lengths?

Flow

What real alternative paths can we guarantee will survive?

Rtop

How much distance has already been paid from this root?

Rflow

Can guaranteed surviving paths and root information strengthen each other?
