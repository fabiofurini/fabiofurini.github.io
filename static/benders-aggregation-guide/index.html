One network, three ways to build Benders cuts

Global, one per root, or one per requested pair: the same shortest paths, organized into different master cuts.

Start with the same graph

This is exactly the five-node directed network of our paper. Each arc is labelled (length, interdiction cost). Arcs in opposite directions use separate curved lanes. For this example we request four pairs: (2,5), (2,3), (2,4), and (3,4).

Step 1 One shortest path for each requested pair

Instead of starting with formulas, look at the four blue paths. They are the individual ingredients of every aggregation level.

Our original follower contribution is 1 + 5 + 4 + 1 = 11. Every Benders variant must represent this same total.

Step 2 Three levels of aggregation

Global

1 master variable

Put all four paths into one cut. Total starting value 11.

By root

2 master variables

Root 2 gets its three paths (10); root 3 gets one (1).

By pair

4 master variables

Each requested pair keeps its own path and its own cut: 1, 5, 4, 1.

Imagine four receipts. Global puts them in one envelope. Root makes two envelopes, one for each origin. Pair keeps four separate receipts. The total amount never changes; only the bookkeeping does.

Step 3 Try an interdiction

Choose a feasible interdiction. The table shows the actual surviving distances; it also makes clear which requested pairs change and which do not.

The three masters bound the same sum. The difference is whether the solver can add and manage one, two, or four separate violated cuts at a time.

Step 4 What does the difference mean for the solver?

Global

One cut from all paths. Smallest master, but violations are aggregated together.

Root

One cut per origin. This is the formulation currently used in v2.

Pair

One cut per requested pair. More precise feedback on individual destinations, but potentially many more cuts.

A key computational advantage: all three can separate cuts with one Dijkstra per active root. Pair disaggregation does not require one Dijkstra for every pair.

Important mathematical conclusion: when all cuts are included and the same valid big-M values are used, the three models have the same complete LP bound. Differences appear in the number and structure of cuts available during the algorithm, not in the final full relaxation.

Only now, the three mathematical forms

Write L(P,x) for the penalized length of a selected path at decision x. All three are upper-bounding Benders cuts:

Global: θ ≤ sum of L(P,x) over every requested pair

Root: θw ≤ sum of L(P,x) over destinations of w

Pair: θwt ≤ L(Pwt,x)

Each formulation includes all possible choices of paths in its respective family. At a fractional master solution, one shortest-path computation per active root finds the paths needed for separation.
